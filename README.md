# My Yaris Care

An iPhone-first maintenance tracker for a 2011 Toyota Yaris hatchback. It stores checklist progress, odometer, detailed refuel entries and service records locally on the device. Its location feature finds nearby fuel stations, links to Apple Maps directions and opens Victoria's official Servo Saver for live prices.

## Publish free with GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `styles.css`, `fuel.css`, `app.js`, and `manifest.webmanifest` to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Open the published link in Safari on iPhone, tap **Share → Add to Home Screen**.
